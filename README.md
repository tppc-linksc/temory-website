# 拾光 Temory 官网

拾光的静态产品官网，部署于 GitHub Pages：<https://temory.tppc.top>。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器打开 <http://127.0.0.1:4173>。

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建依赖
- 默认跟随系统深浅色，也可手动切换并记忆选择
- 响应式布局，支持移动端和减少动态效果偏好
- GitHub Actions 自动部署到 GitHub Pages

产品源代码位于 [tppc-linksc/Temory](https://github.com/tppc-linksc/Temory)。
